Entry for the [make.fun](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) bounty **The Robot Vacuum's Best Excuse**.

The entry is one line, at most 140 characters, giving the funniest excuse a robot vacuum could offer for missing a spot.

## The entry

> I didn't miss that spot. I was giving the dust a head start. Fair fights only — it's in my warranty.

## How to run

```sh
python3 main.py
```

`main.py` copies the committed `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`). Standard library only, no network.
